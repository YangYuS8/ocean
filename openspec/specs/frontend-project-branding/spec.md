## 需求
### 需求:首页必须体现项目业务语境
系统首页必须使用海洋生态样本与设备巡检相关的标题、说明、指标卡片或入口描述，禁止保留模板默认品牌名称、示例文案或与项目无关的模块术语。

#### 场景:查看首页内容
- **当** 用户进入工作台首页
- **那么** 首页必须显示与样本管理、巡检任务、仪器监控或报表工作区相关的项目化内容

### 需求:模板品牌标识必须替换为项目标识
系统必须将模板中的默认品牌标识、应用名称和导航文案替换为符合本项目的名称与术语，以减少使用者混淆。

#### 场景:查看应用标题与导航
- **当** 用户浏览应用标题区、侧边栏或导航头部
- **那么** 用户必须看到项目名称或项目相关术语，而不是模板原始品牌

### 需求:首页必须提供关键业务入口
首页必须提供样本管理、巡检任务、仪器监控、统计报表等核心工作区的快速入口，帮助用户在首次进入时理解系统结构。

#### 场景:从首页进入工作区
- **当** 用户在首页查看主要内容区
- **那么** 用户必须能够直接进入至少一个核心业务工作区入口

### 需求:项目化适配必须兼容当前前端运行方式
前端模板适配后的项目必须继续兼容 Nuxt 4 Node/Nitro、pnpm 和 Nginx 反向代理到 3000 端口的运行方式，禁止要求切换到静态导出或不同包管理器才能正常运行。

#### 场景:在当前开发部署模式下启动前端
- **当** 开发者使用项目约定的 pnpm 与 Docker/Nginx 工作流启动前端
- **那么** 模板适配后的前端必须能够以 Nuxt Node/Nitro 方式正常运行
