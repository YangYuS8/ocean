# Contributing to Ocean

Ocean keeps detailed contributor guidance in the documentation site so English and Simplified Chinese stay in sync.

- English guide: [`website/docs/contributing.md`](website/docs/contributing.md)
- Simplified Chinese guide: [`website/i18n/zh-Hans/docusaurus-plugin-content-docs/current/contributing.md`](website/i18n/zh-Hans/docusaurus-plugin-content-docs/current/contributing.md)

Before opening a pull request, run the checks that match the files you changed and update both English and Simplified Chinese docs when behavior, architecture, roadmap, or operations assumptions change.
