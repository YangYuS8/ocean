## 需求
### 需求:项目必须提供后台工作台框架
前端必须提供适用于海洋样本与巡检系统的后台工作台框架，包含统一的应用壳、页面布局、全局导航和内容区域，而不能继续停留在 Nuxt 默认欢迎页。

#### 场景:访问前端首页
- **当** 用户访问系统前端根路径
- **那么** 系统必须展示项目工作台首页，而不是 Nuxt 默认欢迎界面

### 需求:项目必须提供与业务一致的一级导航
系统必须提供与业务工作区一致的一级导航，至少包含总览、样本管理、巡检任务、仪器监控、统计报表和系统设置入口。

#### 场景:查看主导航
- **当** 用户进入后台工作台
- **那么** 用户必须能够看到与海洋样本和巡检业务一致的一级导航分组

### 需求:项目必须支持响应式工作台访问
工作台布局必须同时支持桌面端和移动巡检场景，在窄屏设备上不得因固定侧栏或溢出布局导致核心导航和页面内容不可达。

#### 场景:在移动设备访问
- **当** 用户使用平板或手机打开工作台
- **那么** 系统必须提供可访问的导航方式并保持核心页面内容可浏览

### 需求:项目必须为后续业务模块预留标准页面入口
系统必须为样本管理、巡检任务、仪器监控、统计报表和系统设置提供标准页面入口；其中样本管理与巡检任务必须在当前 MVP 阶段升级为接入真实业务数据与动作的工作区页面，而不是继续停留在纯占位骨架。

#### 场景:进入模块页面
- **当** 用户点击任一样本管理或巡检任务导航入口
- **那么** 系统必须进入对应真实工作区页面并展示来自后端的业务数据与最小可用操作
- **那么** 其他尚未进入当前 MVP 范围的模块仍可以保留可继续扩展的页面壳或占位内容
