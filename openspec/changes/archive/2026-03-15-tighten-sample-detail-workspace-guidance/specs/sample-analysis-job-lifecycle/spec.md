## 新增需求

### 需求:分析任务状态必须参与样本详情工作台级引导
系统必须让分析任务的当前状态参与样本详情页的页面级工作台摘要与推荐动作，而不能只在分析任务区块内部各自提示。

#### 场景:存在失败分析任务时查看工作台摘要
- **当** 当前样本存在 `failed` 状态的分析任务
- **那么** 系统必须在样本详情页的工作台级引导中提示用户可重新发起分析或转向异常处理

#### 场景:存在运行中分析任务时查看工作台摘要
- **当** 当前样本存在 `queued` 或 `running` 状态的分析任务
- **那么** 系统必须在样本详情页的工作台级引导中将该过程表达为当前样本仍有分析工作待完成

## 修改需求

### 需求:分析任务成功或失败后必须提供后续处理指引
系统必须在分析任务结束后向用户表达该过程的最小结论和下一步处理方向，而不能只停留在技术状态显示层面；这些后续处理指引还必须能够被样本详情页的页面级工作台摘要复用为推荐动作或风险提示。

#### 场景:成功后的后续处理
- **当** 用户在样本详情页查看状态为 `succeeded` 的分析任务
- **那么** 系统必须展示结果摘要（若可用）
- **那么** 系统必须提示用户可继续录入样本结果、记录异常或暂不处理

#### 场景:失败后的后续处理
- **当** 用户在样本详情页查看状态为 `failed` 的分析任务
- **那么** 系统必须展示失败原因（若可用）
- **那么** 系统必须提示用户可重新发起分析或记录异常
