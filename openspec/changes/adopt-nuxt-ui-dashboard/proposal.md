## 为什么

当前前端仍是 Nuxt 最小启动页，缺少适合海洋生态样本与设备巡检系统的后台工作台骨架，导致后续页面、导航、表格、统计卡片和响应式巡检界面都需要从零搭建。现在引入 Nuxt UI Dashboard 模板并在其基础上完成项目化适配，可以显著减少前端基础设施工作量，加快 MVP 页面落地，并让后续样本管理、巡检任务、仪器监控和报表模块建立在统一的信息架构之上。

## 变更内容

- 以 Nuxt UI Dashboard 作为新的前端起点，替换当前 Nuxt 最小示例界面。
- 将模板适配为海洋样本与巡检系统的后台工作台，包括与业务匹配的导航、仪表盘首页、通用布局和响应式交互骨架。
- 统一前端基础能力，如页面框架、全局导航、常用工作区入口、占位数据视图和与现有 Docker/Nginx/Nuxt 运行方式兼容的集成方式。
- 保持现有 Nuxt 4 Node/Nitro、Nginx 反向代理、Docker Compose 和 pnpm 工作流，不引入与当前部署模型冲突的新运行模式。

## 功能 (Capabilities)

### 新增功能
- `frontend-admin-workspace`: 提供适用于样本管理、巡检任务、仪器监控、报表与系统设置的后台工作台框架与导航结构。
- `frontend-project-branding`: 将通用模板界面替换为符合海洋生态业务语境的首页内容、术语、模块入口与视觉标识。
