# backend-laravel-runtime 规范

## 目的
定义基于 Laravel 的后端运行时、数据库初始化主路径与后续扩展边界，作为海洋样本与巡检系统的长期 PHP 承载基础。

## 需求
### 需求:系统必须提供基于 Laravel 的后端运行时
系统必须以 Laravel 作为后端应用运行时，替代当前轻量 PHP 骨架，以承载海洋样本与巡检系统的业务 API。

#### 场景:后端以 Laravel 提供统一入口
- **当** 开发或部署环境启动后端服务
- **那么** 系统必须通过 Laravel 应用入口处理后端请求
- **那么** 系统必须保持与现有 Nginx、Nuxt 3000 端口和 MariaDB/Redis 部署关系兼容

### 需求:系统必须提供 Laravel 数据库迁移与初始化机制
系统必须通过 Laravel migration 和 seeder 管理核心数据库结构与初始化数据，而不再依赖当前自定义脚本作为长期主路径。

#### 场景:初始化核心数据库结构
- **当** 开发或部署环境执行数据库初始化流程
- **那么** 系统必须通过 Laravel migration 创建核心表结构
- **那么** 系统必须通过 Laravel seeder 提供基础角色和必要的初始化数据

### 需求:系统必须允许 Laravel 承载后续认证与队列扩展
系统必须为后续认证、权限控制、Redis 队列和后台任务处理提供框架级扩展基础。

#### 场景:为后续能力保留扩展基础
- **当** 团队后续继续实现认证、权限或 Redis 队列能力
- **那么** 系统必须能够在 Laravel 运行时中扩展这些能力，而不需要重新更换后端承载框架
