## 修改需求

### 需求:结果录入状态必须参与页面级推荐下一步
系统必须将结果录入情况整合进样本详情页的页面级推荐下一步表达，使用户能够直接判断当前是否应优先补录结果，而不是仅在结果区块空态中被动获知；在新的样本工作区信息架构下，结果录入待办还必须能够在样本列表中被预判，而不是只能进入详情后才发现。

#### 场景:样本尚无结果记录
- **当** 当前样本尚无结果记录
- **那么** 系统必须在样本详情页的页面级推荐下一步中将结果录入表达为优先动作之一

#### 场景:样本已有结果记录
- **当** 当前样本已经存在结果记录
- **那么** 系统必须避免继续将结果录入表达为唯一的页面级优先动作
